# 🎭 LAPSUS SOMNII - Narration LAYLA (Musulmane)

## 📖 Concept

**LAYLA** - Architecte, rêve de ponts culturels
- **Genre:** Féminin
- **Design:** Hijab coloré, style professionnel
- **Palette:** Bleu, blanc, or
- **Culture:** Musulmane
