# 🎮 LAPSUS SOMNII - Progression de Difficulté

## 📈 **SYSTÈME DE PROGRESSION NINTENDO**

### **FORMULE DE DIFFICULTÉ:**
- **Vitesse de base:** 1.0x + (Monde × 0.2) + (Niveau × 0.1)
- **Vitesse finale:** Vitesse de base + 0.2x
- **Spawn rate:** 0.5/s + (Monde × 0.1) + (Niveau × 0.05)
- **Temps minimum:** 30s + (Monde × 5) + (Niveau × 5)
