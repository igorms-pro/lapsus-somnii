## 🎯 **INSTRUCTIONS POUR SUNO AI**

### **📝 FORMAT DE PROMPT :**
```
[Style] + [Instruments] + [Tempo] + [Culture] + [Émotion] + [Inspiration] + [Atmosphère]
```

### **🎵 EXEMPLE COMPLET :**
```
"Soft classical music, gentle piano melody, violin accompaniment, peaceful orchestral arrangement, childlike wonder, innocent and dreamy, European classical style, Mozart-inspired, Chopin-like, lullaby feeling, 60-80 BPM, cinematic and emotional"
```

### **⚙️ PARAMÈTRES TECHNIQUES :**
- **Durée:** 2-3 minutes par piste
- **Qualité:** Haute définition
- **Format:** MP3/WAV
- **Volume:** Normalisé
- **Fade:** In/Out doux
