# 🎮 LAPSUS SOMNII - Contenu des Niveaux

## 📖 Concept

**Chaque niveau** a son contenu spécifique avec des **variations culturelles** pour certains personnages.

---

## 🎭 **VARIATIONS CULTURELLES**

### **NIVEAUX AVEC VARIATIONS (4 niveaux):**
1. **Chambre d'enfant** (Monde 1, Niveau 1)
2. **Anniversaire** (Monde 1, Niveau 4)
3. **Nuit de Noël** (Monde 1, Niveau 7)
4. **Mariage** (Monde 4, Niveau 6)

### **NIVEAUX UNIVERSELS (58 niveaux):**
- Tous les autres niveaux restent identiques

---

## 🎮 **MÉCANIQUES DE BASE**

### **OBSTACLES:**
- **Mouvement:** Montent vers le joueur (qui descend)
- **Collision:** Éviter pour continuer
- **Variations:** 1-3 types différents par niveau

### **POWER-UPS:**
- **Mouvement:** Montent vers le joueur
- **Collecte:** Toucher pour activer
- **Variations:** 1-2 types différents par niveau

### **DÉCOR:**
- **Base:** Même thème pour tous
- **Variations:** Style culturel selon le personnage
- **Statique:** Ne bouge pas

### **DIFFICULTÉ:**
- **Temps minimum:** Augmente avec les niveaux
- **Vitesse:** Stable, accélère dans le niveau
- **Spawn rate:** Plus d'obstacles = plus difficile
