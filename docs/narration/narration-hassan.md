# 🎭 LAPSUS SOMNII - Narration HASSAN (Musulman)

## 📖 Concept

**HASSAN** - Ingénieur, rêve d'innovation
- **Genre:** Masculin
- **Design:** Barbe soignée, style moderne
- **Palette:** Vert, blanc, or
- **Culture:** Musulman

---

## 🎮 INTRO DU JEU (Première fois)

**IMAGE:** Chambre de Hassan - lit défait, posters d'ingénierie et d'astronomie sur les murs, bureau avec calculs, fenêtre ouverte sur un ciel étoilé. Hassan (barbe soignée, style moderne) se réveille en sursaut.

**NARRATION:**
```
"As-salamu alaykum! Moi c'est Hassan. Je cherche la vérité.
Dans mon rêve, je vais revivre toute ma vie.
Chaque chute révèle un secret.
Allez, je commence ma descente... Aïe!"
```
