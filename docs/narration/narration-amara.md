# 🎭 LAPSUS SOMNII - Narration AMARA (Africaine)

## 📖 Concept

**AMARA** - Entrepreneure, rêve de changement
- **Genre:** Féminin
- **Design:** Cheveux tressés, style business
- **Palette:** Vert, or, rouge
- **Culture:** Africaine

---

## 🎮 INTRO DU JEU (Première fois)

**IMAGE:** Chambre d'Amara - lit défait, masques africains sur les murs, bureau avec projets d'entreprise, fenêtre ouverte sur un ciel étoilé. Amara (cheveux tressés, style business) se réveille en sursaut.

**NARRATION:**
```
"Akwaaba! Moi c'est Amara. Je cherche la vérité.
Dans mon rêve, je vais revivre toute ma vie.
Chaque chute révèle un secret.
Allez, je commence ma descente... Aïe!"
```
