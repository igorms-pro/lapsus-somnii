# 🎭 LAPSUS SOMNII - Narration ALEX (Européen)

## 📖 Concept

**ALEX** - Artiste créatif, rêve de liberté
- **Genre:** Neutre (pronom "iel")
- **Design:** Cheveux courts blonds, style casual
- **Palette:** Bleu, blanc, rouge
- **Culture:** Européen

---

**IMAGE:** Chambre d'Alex - lit défait, posters d'art sur les murs, chevalet avec toile inachevée, fenêtre ouverte sur un ciel étoilé. Alex (cheveux blonds courts, style casual) se réveille en sursaut.

```
"Salut! Moi c'est Alex. Je cherche la vérité.

Allez, je commence ma descente... Aïe!"
```
